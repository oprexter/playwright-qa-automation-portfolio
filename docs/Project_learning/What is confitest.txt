@pytest.fixture(scope="session", autouse=True)
def set_test_id_attribute(playwright):
    playwright.selectors.set_test_id_attribute("data-test")


-->tells Playwright:
"When I use get_by_test_id(), look for the HTML attribute named data-test.

The simple rule
- autouse=True → Run automatically because every applicable test needs it.
- Normal fixture → Run only when a test or another fixture requests it.


---with autouse=True---

Pytest activates the fixture automatically, so you don't need to mention it in each test.

@pytest.fixture(scope="session", autouse=True)
def set_test_id_attribute(playwright):
    playwright.selectors.set_test_id_attribute("data-test")

def test_login(page):
    page.get_by_test_id("login-button").click()


---Without autouse=True-----

You must explicitly request the fixture in a test or another fixture that depends on it.

@pytest.fixture(scope="session")
def set_test_id_attribute(playwright):
    playwright.selectors.set_test_id_attribute("data-test")

def test_login(set_test_id_attribute, page):
    page.get_by_test_id("login-button").click()
